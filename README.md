# 🧪 Rick & Morty Wiki

Wyszukiwarka postaci z uniwersum Rick and Morty, charakteryzująca się unikalnym, tematycznym stylem wizualnym.

## 🚀 Funkcje
* **Dynamiczne Filtrowanie**: Wyszukiwanie postaci po imieniu przy użyciu oficjalnego API Rick and Morty.
* **Karty Postaci**: Wyświetlanie statusu życia, gatunku i wizerunku postaci z dynamicznym stylowaniem zależnym od ich stanu (Alive/Dead).
* **Stylizacja Neon**: Zaawansowane efekty `text-shadow` i `box-shadow` tworzące portalowy, neonowy klimat.

## 🛠️ Technologie
* **Frontend**: HTML5, CSS3 (Animacje hover, efekty glow)
* **JavaScript**: Asynchroniczne pobieranie danych, renderowanie szablonów HTML
