# 🎬 MovieFinder

Interaktywna wyszukiwarka filmów korzystająca z zewnętrznego API. Pozwala użytkownikom na szybkie znajdowanie informacji o ulubionych produkcjach kinowych.

## 🚀 Funkcje
* **Wyszukiwanie w czasie rzeczywistym**: Możliwość wyszukiwania filmów po tytule poprzez integrację z API OMDb.
* **Szczegółowe informacje**: Wyświetlanie metadanych takich jak ocena IMDb, opis fabuły, gatunek i obsada w oknie modalnym.
* **Responsywny Design**: Interfejs oparty na siatce (CSS Grid), który dostosowuje się do urządzeń mobilnych i stacjonarnych.
* **Obsługa UX**: Możliwość zatwierdzania wyszukiwania klawiszem Enter.

## 🛠️ Technologie
* **Frontend**: HTML5, CSS3 (Grid, Flexbox)
* **JavaScript**: ES6+, Fetch API, Async/Await
