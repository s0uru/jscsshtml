# ☁️ Weather App

Nowoczesna aplikacja pogodowa wykorzystująca efekt Glassmorphism do prezentacji danych meteorologicznych dla wybranych miast.

## 🚀 Funkcje
* **Pobieranie Danych**: Integracja z API pogodowym w celu uzyskania informacji o temperaturze, wilgotności i wietrze.
* **Interfejs Glassmorphism**: Wykorzystanie nowoczesnych technik CSS, takich jak `backdrop-filter`, dla uzyskania efektu rozmytego szkła.
* **Animacje**: Płynne pojawianie się danych pogodowych po ich pobraniu dzięki animacjom `@keyframes`.

## 🛠️ Technologie
* **Frontend**: HTML5, CSS3 (Glassmorphism, Grid)
* **JavaScript**: Async/Await, Fetch API, manipulacja DOM
