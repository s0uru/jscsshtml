# 🍰 Shopping Cart System

Aplikacja symulująca proces zakupowy w cukierni, skupiająca się na zaawansowanej logice zarządzania danymi w JavaScript.

## 🚀 Funkcje
* **Zarządzanie Koszykiem**: Dodawanie produktów, grupowanie tych samych pozycji oraz usuwanie całej zawartości.
* **Automatyczne Obliczenia**: Dynamiczne przeliczanie sumy częściowej, podatku (8.25%) oraz kwoty całkowitej.
* **Programowanie Obiektowe**: Cała logika koszyka została zamknięta w klasie `ShoppingCart`, co ułatwia zarządzanie stanem aplikacji.

## 🛠️ Technologie
* **Frontend**: HTML5, CSS3 (zmienne CSS, Flexbox)
* **JavaScript**: Klasy ES6, metody tablicowe (`reduce`, `forEach`, `find`)
