# 🎹 GLASS.mp3 Drum Machine

Interaktywna maszyna perkusyjna łącząca nowoczesny design z obsługą zdarzeń multimedialnych.

## 🚀 Funkcje
* **Obsługa Audio**: Odtwarzanie 9 różnych sampli perkusyjnych z niskim opóźnieniem.
* **Kontrola Klawiaturą**: Pełne wsparcie dla skrótów klawiszowych (Q, W, E, A, S, D, Z, X, C).
* **Animowane Tło**: Złożone animacje CSS imitujące poruszające się świetliki oraz dynamiczne gradienty.
* **Visual Feedback**: Dynamiczna aktualizacja wyświetlacza oraz wizualne efekty naciśnięcia padów.

## 🛠️ Technologie
* **Frontend**: HTML5 Audio, CSS3 (Keyframes, Glassmorphism)
* **JavaScript**: Event Listeners (click, keydown), DOM Manipulation
